## 原生 IP、住宅 IP、双 ISP：三层概念，别混着用

多数法国 VPS 页面把这三个词当同义词用，实际是三件不同的事，价钱也差在这三层上。

**原生 IP** 只说明归属。朝暮数据官方 FAQ 的定义是“IP 地址的运营商所在国家和服务器的地理位置一致”。一台放在巴黎、IP 注册在法国的机器就是原生 IP，仅此而已，和 IP 好不好用无关。

**住宅 IP** 说明 ISP 属性。它由宽带运营商分配给家庭或个人用户，而不是数据中心段。平台看到的是“某法国家庭宽带”，与“某机房”是两种画像。

**双 ISP** 在住宅属性上再叠一层 ISP 信息，让 IP 的注册与路由归属更接近真实宽带用户。

三层叠加不等于能解锁流媒体。RackNerd 的斯特拉斯堡机房用的是原生法国 IP，属于数据中心段，Netflix 非自制剧照样受限。买之前把“原生”当成“能看 Netflix”，是最常见的误判。

WePC 法国线在第三方评测里被描述为“双 ISP 原生住宅 IP”，机房在普罗旺斯，这个位置在欧洲 VPS 里确实少见。它对应的是账号环境模拟这类需求，而不是流媒体解锁。

## “IP 纯净度评分”到底该不该信

法国 VPS 测评里常见“原生 IP 纯净度很高”这类说法，也有商家直接在 FAQ 里否认这套口径。朝暮数据的官方说法是：某些网站提供的 IP 欺诈值检测并没有评分依据，IP 地址本身没有纯净、干净、新老之分，TikTok 这类平台有自己的 IP 地址库和检测手段。

两种说法指向同一件事的两面。评分站给的是概率参考，不是平台的实际判定，同一段 IP 在不同评分站上分数经常对不上。能自己查的部分是明确的：

1. 用 ipinfo 查 IP 的注册国家与 ASN，确认归属国是法国
2. 用 scamalytics 看该段 IP 被标记的类型，重点看是否落在数据中心段
3. 用 whoer 交叉验证 DNS、时区、语言与 IP 归属是否一致

三个平台结果一致，说明基础属性没问题，剩下的只能靠实际业务跑一段时间看表现。这也是不建议一上来就年付的原因。
